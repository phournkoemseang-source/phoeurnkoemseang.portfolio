## Overview

Developed a responsive music web app with user authentication and role-based access.

## Key Features

- Play/pause and next/previous controls
- Song upload functionality
- Real-time search that auto-suggests songs while typing
- User authentication and role-based access
- Smooth functionality with Firebase and LocalStorage

## Technologies Used

- **HTML** - Structure
- **CSS** - Styling
- **Bootstrap 5** - UI framework
- **JavaScript** - Frontend logic
- **Firebase** - Backend services
