## Overview

Developed a simple yet luxurious premium dining website with a dark aesthetic, optimized for a high-end user experience. Built using Vue as the primary frontend framework.

## Key Features

- Interactive food ordering system
- Table reservation module for dating and special events
- Fully responsive frontend with modern styling and smooth animations
- Database management and storage solutions using MySQL
- Comprehensive API endpoint testing using Postman and Apidog

## Technologies Used

- **Vue** - Core UI framework (80.5%)
- **JavaScript** - Core programming (16.2%)
- **TypeScript** - Type safety (2.9%)
- **MySQL** - Database management
