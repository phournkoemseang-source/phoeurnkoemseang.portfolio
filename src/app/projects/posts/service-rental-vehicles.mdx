## Overview

Developed a web platform for vehicle rental (motorbikes, bicycles, and cars) enabling users to search nearby shops, view available vehicles, select rental duration, and book instantly.

## Key Contributions

- Contributed to frontend development using Vue.js
- Backend development with Laravel
- MySQL database integration
- Used Postman for testing API endpoints
- Collaborated using Jira, GitHub, and AI tools
- Assisted in UX/UI design
- Deployed the application on AWS
