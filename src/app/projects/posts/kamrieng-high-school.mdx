## Overview

A real, production website for Kamrieng High School, a public high school in Kamrieng district, Battambang province, Cambodia. The site serves students, parents, and staff with school news, event announcements, student achievements, and admissions information — fully bilingual in Khmer and English.

## Key Features

- Bilingual Khmer/English interface with language switching
- School news and event announcements with public exam schedules
- Student achievements and school information sections
- Admissions documents and official school resources
- Responsive, accessible design optimized for both mobile and desktop

## Technologies Used

- **Next.js** - Full-stack framework for both frontend and backend (API routes & server logic)
- **TypeScript** - Core language (92.5%)
- **JavaScript** - Interactivity (4.1%)
- **PLpgSQL** - Database procedures and functions on Supabase (2.8%)
- **CSS** - Styling (0.6%)
- **Firebase** - Additional data management
- **Supabase** - PostgreSQL database and backend services

## Deployment

Deployed on Vercel for production hosting, with a live demo available for the English version of the site.
