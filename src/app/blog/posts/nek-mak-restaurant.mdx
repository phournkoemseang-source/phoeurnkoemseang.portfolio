## Overview

NekMak Restaurant is a simple yet luxurious premium dining website, designed to deliver a high-end user experience from the first scroll. It combines a striking dark aesthetic with interactive features that actually run a restaurant's online ordering — not just a static brochure.

## The Problem

Diners expect more from a restaurant's website these days. They want to browse the menu, place an order, and reserve a table without picking up the phone. The challenge was building that experience to feel premium while keeping it fast and reliable on any device.

## The Tech Stack

NekMak is built with **React** and **JavaScript**, with **Firebase** powering the real-time data layer — menu items, orders, and reservations all live in the cloud and sync instantly.

### Why Firebase

Choosing Firebase meant orders and reservations could update in real time without building a custom backend. New menu items, sold-out dishes, and incoming reservations all propagate instantly — which is exactly what a busy restaurant needs.

## Key Features

- Interactive **food ordering system**
- **Table reservation module** for dating and special events
- Fully **responsive** frontend with modern styling and smooth animations
- **Real-time data management** with Firebase

## What I Learned

1. **Real-time data changes the UX.** When orders update live, users trust the product more — they can see their order land in the system.
2. **A dark aesthetic needs discipline.** Getting contrast, spacing, and animation timing right makes the difference between 'premium' and 'hard to read'.
3. **Firebase removes friction.** For a project like this, skipping a custom backend let the team focus on the experience users actually see.
