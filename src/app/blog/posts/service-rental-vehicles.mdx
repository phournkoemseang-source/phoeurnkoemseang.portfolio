## Overview

Service Rental Vehicles is a full-stack web platform for renting motorbikes, bicycles, and cars. Users can search for nearby rental shops, browse available vehicles, pick a rental duration, and book instantly — all in one flow.

It was built as a team project (VC1) with a mentor, developers, QA, and a Scrum Master, which made it as much a lesson in collaboration as in code.

## The Problem

Renting a vehicle usually means calling around to shops. The platform replaces that with:

- **Search nearby shops** that have vehicles available
- **View available vehicles** with details and pricing
- **Select rental duration** and **book instantly**
- A single experience that works for **motorbikes, bicycles, and cars**

## The Tech Stack

The frontend is built with **Vue.js** and the backend with **Laravel (PHP)**, backed by **MySQL** for data. **Postman** was used to test API endpoints throughout development.

## What I Learned

1. **Full-stack means owning the whole flow.** Building both the Vue frontend and Laravel backend taught me how a booking request travels from a button click to the database and back.
2. **Team process is real.** A Scrum Master, QA roles, and Jira boards turned a busy team into a coordinated one — that structure was what let us ship.
3. **Test endpoints before UI.** Postman testing against MySQL caught contract mismatches early, so the Vue components never fought the API.
