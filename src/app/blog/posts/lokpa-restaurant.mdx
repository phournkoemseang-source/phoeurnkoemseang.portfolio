## Overview

LokPa Restaurant is a premium dining website built to feel as luxurious as the restaurant itself. The dark aesthetic, smooth animations, and refined typography create a high-end experience — while underneath, a full ordering and reservation system keeps the business running.

It's the kind of project where frontend polish and backend engineering have to work together: an interactive menu, a working cart, and reservations that actually reach the restaurant.

## The Vision

A restaurant website can't just look good — it has to convert visitors into customers. The goals were:

- An **interactive food ordering system** that feels effortless
- A **table reservation module** for dating and special events
- A **premium dark aesthetic** with smooth animations
- A backend that can **manage menu data and orders reliably**

## The Tech Stack

I chose Vue as the core UI framework, paired with TypeScript for type safety on top of JavaScript. MySQL handles the database, and Postman + Apidog were used to test every API endpoint.

### Key Pieces

- **Vue** — component-driven frontend that keeps the UI organized as the app grows
- **MySQL** — relational storage for menus, orders, and reservations
- **Postman & Apidog** — API testing throughout development, catching bugs before they ship

## Key Features

- Interactive **food ordering system**
- **Table reservation module** for special events
- Fully **responsive** frontend with modern styling and smooth animations
- **MySQL** database management for menu and order data
- Comprehensive **API endpoint testing** with Postman and Apidog

## What I Learned

1. **Aesthetic matters, but so does architecture.** The dark premium look is what users remember, but the component structure and API design are what make it maintainable.
2. **TypeScript pays for itself.** Even at a small percentage of the codebase, it caught real bugs in the Vue components early.
3. **Test your APIs before you build the UI.** Postman and Apidog let me validate every endpoint against MySQL before wiring up the interface — saving a lot of debugging later.
